# 亲戚计算器 - 微信小程序版

中国亲戚关系智能计算工具的小程序版本，基于 AI 技术帮助用户快速理清复杂的亲戚关系。

## 功能特性

- **智能关系计算**：输入关系链（如"我妈妈的哥哥的妻子"），AI 自动计算正确称呼
- **可视化关系图谱**：使用 Canvas 绘制关系网络图，支持拖拽和缩放
- **详细计算步骤**：展示每一步的推理过程和逻辑解释
- **便捷输入**：提供快捷按钮，一键添加常见亲戚关系
- **精美 UI**：与原 Web 版本保持一致的现代化设计风格

## 部署指南

### 1. 准备工作

- 注册微信小程序账号
- 下载并安装微信开发者工具
- 开通微信云开发环境

### 2. 导入项目

1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择 `miniprogram` 文件夹
4. 填写你的小程序 AppID
5. 选择"使用云开发"

### 3. 配置云开发

1. 在微信开发者工具中点击"云开发"按钮
2. 创建云开发环境（如未创建）
3. 记录环境 ID
4. 修改 `pages/index/index.js` 中的 `env: 'your-env-id'`

### 4. 部署云函数

1. 在微信开发者工具中右键 `cloudfunctions/calculateKinship`
2. 选择"创建并部署：云端安装依赖"
3. 等待部署完成

### 5. 配置 AI API（可选）

默认使用本地模拟数据，如需接入真实 AI：

1. 在百度千帆平台申请 API Key
2. 在云开发控制台添加环境变量 `BAIDU_QIANFAN_API_KEY`
3. 重新部署云函数

### 6. 发布小程序

1. 在微信开发者工具中点击"上传"
2. 登录微信公众平台
3. 提交审核
4. 审核通过后发布

## 使用说明

1. 在输入框中输入亲戚关系链（如"妈妈的哥哥"）
2. 或点击下方快捷按钮快速构建关系链
3. 点击"计算关系"按钮
4. 查看计算结果和关系图谱
5. 点击"查看计算过程"了解详细推理步骤

## 技术栈

- 微信小程序原生开发
- 微信云开发（云函数）
- Canvas 2D 关系图谱
- 力导向图布局算法

## 注意事项

- 小程序需要用户授权网络请求
- 云开发有免费额度限制
- 建议使用基础库 2.19.4 及以上版本

## 与原 Web 版本的差异

1. **图表库**：使用原生 Canvas 2D API 替代 D3.js
2. **网络请求**：使用 wx.request 和云函数替代 fetch
3. **状态管理**：使用小程序原生数据绑定替代 React useState
4. **样式单位**：使用 rpx 替代 px，适配各种屏幕尺寸
