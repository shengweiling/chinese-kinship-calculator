# 中国亲戚关系计算器

春节将至，面对复杂的亲戚关系不知道如何称呼？这款亲戚计算器可以帮你轻松解决这个难题！

## 功能特点

- **智能称呼计算**：输入亲戚关系链，自动计算出最终的称呼
- **详细计算步骤**：展示清晰的关系推导过程
- **关系图谱可视化**：以图形方式展示亲戚关系网络
- **支持复杂关系**：能够处理各种复杂的姻亲、旁系亲属关系

## 技术实现

- **前端框架**：React 19 + TypeScript
- **AI服务**：百度千帆 ERNIE 4.5 Turbo
- **可视化**：D3.js 关系图谱
- **构建工具**：Vite

## 使用方法

1. 在输入框中描述亲戚关系（如："爸爸的姐姐的丈夫"）
2. 点击计算按钮，系统会自动分析并给出结果
3. 查看计算步骤和关系图谱

## 核心规则

- 默认从"我"的角度出发进行计算
- 对于复杂关系会转化为社交场景下的单一直接称呼
- 遵循中国传统亲属关系称呼习惯

## 启动项目

```bash
npm install
npm run dev
```

访问 http://localhost:3000 即可使用。
